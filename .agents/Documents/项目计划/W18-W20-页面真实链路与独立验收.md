## 页面与安全边界

- 总览使用 `/metrics/overview` 的去重口径，最新 Trace 来自 `/traces`，不混入假实时数据。
- Trace 列表按项目、环境、时间范围、精确 Trace ID、服务、状态查询，分页受后端 offset 上限约束。详情携带项目、具体环境与列表时间窗；全部环境不能作为详情环境。
- 详情使用有效父子树与迭代遍历，提示孤儿、环、多根和截断；保留原始父 ID 与切环后的有效关系区别。耗时按时间轴展示，不累加并行节点。
- AI 指标仅展示 API 已提供的模型调用、Token、延迟/TTFT、RAG 成功与空召回、召回/重排耗时。没有采样显示“—”，未配置模型价格不伪造金额，也不把召回数量当质量评分。
- 全局范围变化立即隐藏旧范围结果，并取消旧请求；空态、加载、失败重试均不回退为 mock。
- 管理令牌只在本地 Vite 服务端读取。代理限定同源、本机、精确 GET 路径与合法参数，禁止内容读取、写请求和管理子路径；不转发浏览器提供的凭证或敏感上游错误。
- 该代理仅用于本地开发，不挂载到 preview/生产。平台管理员鉴权不是项目成员 RBAC；生产需要正式登录/BFF 与权限控制。

## 验收方法

先运行 build/typecheck 与 API、前端、contracts、Collector、relay 测试。使用 Playwright CLI 实际打开浏览器，先读取快照再操作，必要时通过 run-code 执行可复用的断言和网络故障注入；不以单元测试或 HTTP 200 代替页面验收。

`scripts/w18-page-acceptance-session.cjs` 创建随机项目、Topic/消费组、自有 API/Collector/Vite 进程与空闲端口，使用本地 OpenAI/Qdrant 协议服务生成六种真实调用，经过 Kafka → Collector → ClickHouse。另造同 Trace ID 的跨项目/环境记录、孤儿/环以及 2,001 层链路。浏览器再通过自身 `apiFetch` 发起成功/限流请求，验证生成的 Trace ID 可以在页面回查五个服务端 Span。

网络故障注入仅用于加载、错误重试和竞态状态测试；正常页面数据与管道读取不 mock。敏感原文放置 canary，检查实际响应、页面、浏览器存储和构建产物；不把凭证写入报告。结束时按项目 UUID/slug、独立 Topic/消费组及自有进程清理，不删除共享卷或用户数据。

Collector 使用构建产物，原有 `tsx watch` 问题不在本轮修复。使用本地协议服务不代表远程付费模型、真实 Qdrant 引擎或检索质量已验收。时间窗、迟到/丢失 Span 与后端 2,000 Span 上限仍会影响完整性。

### 独立审查

最终复核未发现本轮范围内未解决的阻塞问题。审查覆盖前端状态/请求生命周期、契约一致性、树遍历复杂度、参数权限边界、上游资源预算、凭证与内容泄漏，以及移除旧实现后的引用完整性。

| 审查发现 | 修正与复验 |
| --- | --- |
| 客户端曾把 Span ID 当作 Trace ID 校验，拒绝契约允许的非 ASCII/斜线标识 | 使用独立 Span ID 校验；孤儿/环及深树测试通过 |
| 代理路径候选判断过宽，误拦截 Vite 源模块，导致页面空白 | 精确管理路径边界；静态模块放行测试与实际浏览器首屏通过 |
| 只有 socket 空闲超时不足以限制持续滴流的上游 | 加入绝对截止时间、客户端取消和响应体大小限制；滴流超时单测通过 |
| 分页超过 API offset 上限、项目切换保留旧结果存在风险 | 限制可翻页范围，取消请求并按 scope 隔离显示；分页及切项目浏览器检查通过 |
| 旧 mock Trace/AI 组件可能造成两套实现混用 | 删除旧实现；演示告警不再跳转真实 Trace，明确保留后续范围 |
| 缺失 usage/TTFT、跨时间窗或截断容易被误解 | 缺失值显示“—”，明确窗口/迟到数据与截断提示；真实 noUsage 与深树复验通过 |
| 窄屏执行树的耗时值被横向布局遮挡 | 对 live 树单独设置响应式列宽；480px 下几何断言及截图复查通过 |

验收脚本的第一次响应体审计曾等待取消请求而无法结束；修正为仅审计已完成响应、设置有限超时并保留失败断言。停止的准备会话均报告失败并清理通过，没有把它们当作成功。最终成功记录使用全新隔离数据。
