## 使用与边界

平台 API 默认关闭埋点。设置 SERVER_TRACE_ENABLED=true，并配置已注册项目 UUID、服务名和环境，重启后查看 health 的 tracing.state。未注册或依赖失败只停用埋点，不停止业务。运行期绑定状态不热更新，变更后必须重启。

Nest Guard、body parser 和无匹配路由发生在 interceptor 之前，当前不产生 root；health 和 spans 路径主动排除。关闭监控时业务应先判断 TraceContext.current()，不能无条件调用需要有效上下文的 withSpan。

属性脱敏不是任意自由文本识别器；开发者必须只设置安全元数据。Recorder 的参数校验会对无效开发调用抛错；网络 sink 的错误被隔离。直接调用时 sink 必须仅排队，不能同步执行慢 I/O。

测试 RAG/LLM Span 是执行树合成样例，未访问 OpenAI 或 Qdrant。本轮未更改 Collector 的 tsx watch 命令，真实验收使用已构建 Collector；热更新未作为本轮验收通过项。

没有新增依赖、数据库迁移或 Compose 服务；没有修改真实 .env，也没有提交或推送 Git。
